# CytoOrg-ImageJ

ImageJ/Fiji macro for quantitative analysis of cellular cytoskeletal organization from fluorescence microscopy images.

## Overview

CytoOrg is an automated analysis pipeline developed to quantify cytoskeletal architecture, including filament thickness, branching, and orientation parameters.

The macro is designed for fluorescence microscopy images and provides quantitative descriptors of cytoskeletal organization.

## Features

- Cytoskeleton segmentation and enhancement
- Filament thickness estimation
- Skeleton-based filament analysis
- Branching and junction quantification
- Filament length and density measurements
- Orientation analysis
- Automated result export

## Requirements

- Fiji (ImageJ2)
- BoneJ Local Thickness
- OrientationJ
- AnalyzeSkeleton
- Tubeness filter

## Installation

1. Download the `CytoOrg.ijm` file.
2. Open Fiji/ImageJ.
3. Run the macro through:
   
   `Plugins → Macros → Run`
